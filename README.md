ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ приложения «Слушалка»

1. Общие положения
Настоящая политика описывает, как приложение «Слушалка» (далее — Приложение)
обрабатывает данные пользователей. Политика распространяется на все версии
Приложения, публикуемые в RuStore.

2. Какие данные обрабатывает Приложение
Приложение не собирает, не хранит на серверах, не передаёт и не продаёт
персональные данные пользователей. Вся информация, необходимая для работы,
обрабрабатывается локально на устройстве:
— список аудиофайлов и их метаданные (название, исполнитель, альбом,
  длительность) читаются из системной медиатеки устройства;
— прогресс прослушивания, настройки эквалайзера и сохранённые радиостанции
  хранятся только в локальной базе данных Приложения;
— данные не покидают устройство; реклама и аналитика отсутствуют.

3. Разрешения Приложения
— Доступ к аудиофайлам (READ_MEDIA_AUDIO): используется исключительно для
  отображения и воспроизведения аудиофайлов пользователя. Приложение не
  изменяет и не удаляет файлы.
— Доступ к сети (INTERNET): используется только для воспроизведения
  интернет-радиостанций, которые пользователь добавляет или выбирает сам.
— Фоновое воспроизведение: служба нужна, чтобы аудио продолжало играть при
  выключенном экране и управлялось из шторки уведомлений.

4. Интернет-радио
При прослушивании интернет-радиостанций Приложение обращается к серверам
соответствующих станций. При этом ваш IP-адрес и служебная информация
соединения становятся доступными этим серверам — так же, как при
прослушивании той же станции в любом другом плеере. Разработчик Приложения
эти данные не получает и не хранит.

5. Дети
Приложение не собирает данные пользователей, включая данные детей.

6. Изменения политики
Актуальная версия политики всегда доступна по этому адресу. При
существенных изменениях обновляется дата в начале документа.
